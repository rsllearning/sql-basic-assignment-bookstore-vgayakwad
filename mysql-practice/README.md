# Basic SQL Assignment – Online Bookstore

## Assignment Overview

This assignment demonstrates SQL fundamentals through a database designed for an online bookstore.

The objective is to create and populate relational database tables and write SQL queries to retrieve, filter, sort, analyze, and manage book and author information.

- Concepts Covered

- Database and table creation

- Data insertion and manipulation

- Data retrieval using SELECT

- Filtering using WHERE, BETWEEN, and LIKE

- Sorting using ORDER BY

- Removing duplicates using DISTINCT

- Aggregate functions and grouping

- Joins: INNER JOIN, LEFT JOIN, and RIGHT JOIN


## Steps to Execute the SQL Script

### Prerequisites

- MySQL Server installed and running
- MySQL command-line client or MySQL Workbench
- clone/download file `basic-sql-assignment.sql` from github

### Option 1: Execute Using MySQL Terminal

- Open Terminal.
- Log in to MySQL: 
   mysql -u root -p

- Execute the SQL script using its full file path:

- SOURCE /path/to/basic-sql-assignment.sql;

- Replace /path/to/ with the actual directory containing the file.





# Advanced SQL Assignment – Online Store

## Assignment Overview

This assignment demonstrates advanced SQL concepts through a database designed for an online store.

The objective is to write SQL queries to perform complex data retrieval, analyze customer purchases, manage transactions, automate actions using triggers, and improve query performance.

### Concepts Covered:

- Subqueries and nested queries

- Aggregate functions and advanced grouping with GROUP BY and HAVING

- Set operations using UNION

- Common Table Expressions (CTEs)

- Recursive CTEs

- Window functions: RANK(), DENSE_RANK(), and ROW_NUMBER()

- Views and their use cases

- Index creation and usage

- Transactions using START TRANSACTION, COMMIT, and ROLLBACK

- Stored procedures and conditional logic

- Triggers for automated audit logging

- Query optimization and performance tuning

- Index-friendly filtering and date-range queries

- Using EXPLAIN to analyze query execution plans

### Database Schema

The assignment uses the following tables:

Customers: Stores customer information, including name, city, and email.

Products: Stores product details, including name, category, price, and creation date.

Orders: Stores order details, including customer, product, quantity, and order date.

ORDER_AUDIT: Stores audit information generated by database triggers.

Steps to Execute the SQL Script

### Prerequisites

- MySQL Server installed and running

- MySQL command-line client or MySQL Workbench

- Clone or download the advanced-sql-assignment.sql file from GitHub

- Option 1: Execute Using MySQL Terminal

Open Terminal.

Log in to MySQL:

mysql -u root -p

Execute the SQL script using its full file path:

SOURCE /path/to/advanced-sql-assignment.sql;

Replace /path/to/ with the actual directory containing the SQL file.

Option 2: Execute Using MySQL Workbench

Open MySQL Workbench and connect to your MySQL server.

Open advanced-sql-assignment.sql.

Execute the script using the lightning bolt button.

Review the output and verify that the tables, procedures, triggers, and queries execute successfully.
